# Feetech STS 버스 서보 테스트 도구

Feetech STS 시리즈(STS3215 등) 버스 서보를 USB 어댑터로 연결해서 상태를 읽고, 구동하고, 정밀도를 측정하는 도구 모음입니다.
Windows, macOS, Linux에서 동작하고, 어댑터가 USB 시리얼로 인식되면 포트를 자동으로 찾습니다.

## 준비물

| 항목 | 내용 |
|---|---|
| 서보 | Feetech STS 시리즈 (예: STS3215-C001, 7.4V형, 기본 ID 1, 1 Mbps) |
| 어댑터 | USB 버스 서보 어댑터 (예: Waveshare Bus Servo Adapter (A) - 점퍼를 **B(USB)** 쪽으로) |
| 전원 | 서보 정격에 맞는 외부 DC 전원. 7.4V형은 **5~7.4V**, 서보 1개 테스트는 1~2A 이상 |
| 케이블 | 데이터 통신이 되는 USB 케이블 (충전 전용 케이블 X), 서보 3핀 케이블 |
| PC | Python 3.9 이상 |

> 어댑터의 입력 표기(예: 9~12V)는 보드 기준입니다. 보드는 입력 전압을 그대로 서보에 넘기므로 **서보 정격 전압**에 맞춰야 합니다.

## 빠른 시작 - 웹 콘솔

### Windows
`start_web.bat`을 더블클릭합니다.
처음 실행하면 `.venv` 가상환경을 만들고 패키지를 설치합니다. 인터넷 연결이 필요하고, 1~2분 걸립니다. 그다음 브라우저가 열립니다.

### macOS / Linux
```bash
sh start_web.sh
```

### 직접 실행
```bash
python -m pip install -r requirements.txt
python servo_web.py
```

브라우저 주소는 `http://127.0.0.1:8765` 입니다. 이 PC에서만 접속할 수 있습니다.
콘솔 창에서 **Ctrl+C**를 누르면 모든 서보의 토크를 끄고 종료합니다.

## 파일 구성

| 파일 | 설명 |
|---|---|
| `servo_web.py` + `web/index.html` | **웹 콘솔.** 여러 서보 검색, 개별/그룹 구동, 실시간 그래프(위치·전류·부하·온도), CSV 기록 |
| `servo_monitor.py` | 터미널 실시간 모니터와 위치 제어 (`--plot`은 그래프 창, `--readonly`는 읽기만) |
| `servo_precision_test.py` | 정밀도 테스트: 미세 스텝, 방향별 반복 정밀도와 히스테리시스, 스텝 응답(CSV/PNG) |
| `servo_recenter.py` | 서보를 중앙(2048)으로 천천히 이동한 뒤 토크 OFF (과전류·걸림 시 자동 중단) |
| `servo_common.py` | 공통 모듈: 포트 자동 검색, 상태 읽기, OS별 키 입력, 한글 폰트 |
| `sts_compat.py` | STS용 SDK 래퍼 (`feetech-servo-sdk` 1.0.0 기반) |
| `start_web.bat` / `start_web.sh` | 가상환경 자동 준비 후 웹 콘솔 실행 |

## 각 스크립트 사용법

모든 스크립트는 `--port`를 생략하면 어댑터를 자동으로 찾습니다.
가상환경을 쓰는 경우 `python` 대신 `.venv\Scripts\python`(Windows) 또는 `.venv/bin/python`(macOS/Linux)을 쓰세요.

```bash
python servo_web.py --scan 0-20 --hz 20       # 웹 콘솔 (ID 0~20 검색)
python servo_monitor.py                       # 터미널 모니터 + 제어
python servo_monitor.py --plot                # 실시간 그래프 (읽기 전용)
python servo_precision_test.py --range 300    # 정밀 테스트 (중앙 ±300스텝)
python servo_recenter.py                      # 중앙으로 이동
```

포트 이름 예시: Windows는 `COM13`, Linux는 `/dev/ttyUSB0` 또는 `/dev/ttyACM0`, macOS는 `/dev/cu.usbserial-xxxx` 또는 `/dev/cu.wchusbserialxxxx` 입니다.

### 터미널 모니터 명령 (`servo_monitor.py`)

| 입력 | 동작 |
|---|---|
| `on` / `off` | 토크 ON (현재 위치 유지) / OFF |
| `2100`, `180d` | 절대 위치 [스텝] / [°] |
| `+50`, `-10d` | 현재 목표 기준 상대 이동 |
| `c` | 중앙(2048) |
| `v 500`, `a 30` | 기본 속도 [스텝/s], 가속도 [100스텝/s²] (0 = 최대) |
| `2100 v1000 a10` | 이번 이동에만 속도/가속도 지정 |
| ← → / ↑ ↓ | ±1 / ±10 스텝 |
| `q`, Ctrl+C | 종료 (토크 OFF) |

## 안전 동작

- 토크를 켤 때 목표 위치를 현재 위치로 먼저 맞춰서, 켜자마자 튀지 않습니다.
- 종료, 연결 해제, 오류가 나면 토크를 끕니다. 웹 콘솔은 브라우저 창을 모두 닫고 3초가 지나도 토크를 끕니다.
- 웹 콘솔에서는 **Esc** 키나 **전체 토크 OFF** 버튼으로 모든 서보의 토크를 바로 끌 수 있습니다.
- 이 도구들은 **EEPROM(ID, 보드레이트, 각도 제한, PID 등)에 쓰지 않습니다.** 전압 범위(주소 14, 15)는 경고 기준으로 쓰기 위해 읽기만 합니다.
- 위치 모드에서는 0/4095 경계를 넘어가지 못합니다. 예를 들어 4000에서 100으로 가라고 하면 **반대 방향으로 약 348°를 돌아서** 갑니다. 로봇팔에 조립한 상태라면 관절마다 움직일 수 있는 범위를 먼저 확인하세요.

## 여러 서보를 연결할 때

- 같은 버스의 서보는 **ID가 모두 달라야** 합니다. 공장 출하 상태는 전부 ID 1이라, 그대로 여러 개를 연결하면 응답이 충돌합니다. ID 변경 기능(EEPROM 쓰기)은 아직 포함돼 있지 않습니다.
- 전원 전압은 서보 개수와 상관없이 같고, 전류만 더해집니다. 동시에 움직이는 서보 1개당 1~1.5A를 잡으세요.
- 서보 하나를 읽는 데 2~5ms가 걸립니다. 서보가 많아지면 갱신 주기(Hz)가 그만큼 떨어집니다.

## 문제 해결

| 증상 | 확인할 것 |
|---|---|
| 어댑터를 찾지 못함 | 데이터 USB 케이블인지. Windows: 장치 관리자 > 포트에 보이는지, CH340/CH343 드라이버(WCH). macOS: `ls /dev/cu.*`. Linux: `ls /dev/ttyUSB* /dev/ttyACM*` |
| 포트 열기 실패 / 권한 없음 | 다른 프로그램(다른 스크립트, 웹 콘솔, 시리얼 모니터)이 포트를 쓰고 있는지. Linux는 `sudo usermod -aG dialout $USER` 후 다시 로그인 |
| 서보 응답 없음 | 외부 전원이 들어가는지, 어댑터 점퍼 위치, 3핀 케이블 방향, ID와 보드레이트(웹 콘솔에서 ID 범위나 보드레이트를 바꿔서 검색) |
| 전압 경고 | 서보에 설정된 최대 전압(7.4V형은 8.0V)을 넘는 전원. 전원 전압을 낮추세요 |
| 웹 콘솔이 안 열림 | 이미 실행 중이거나 8765 포트를 다른 프로그램이 쓰는 중 → `--http 8800` 처럼 포트 변경 |
| 그래프 한글 깨짐 | 한글 폰트 설치 (Linux: `sudo apt install fonts-nanum`) |

## 정밀 테스트 결과 해석 기준

- 반복 정밀도: 표준편차 1스텝 이하, 최대 오차 2~3스텝 이내면 양호
- 미세 스텝: 1~2스텝 명령에 반응이 없으면 데드존 영향일 수 있음 (불량이 아닐 수 있음)
- 히스테리시스: 몇 스텝 정도는 정상, 크면 기어 유격이나 데드존 문제
- 스텝 응답: 오버슈트가 크거나 목표 근처에서 진동이 계속되면 이상
- 불량 의심: 통신 무응답, 위치 값이 튀거나 고정됨, 무부하인데 전류가 큼, 급격한 발열

## 주요 레지스터 (STS 시리즈)

| 주소 | 내용 | 주소 | 내용 |
|---|---|---|---|
| 5 | ID (EEPROM) | 46 | 목표 속도 (2B) |
| 6 | 보드레이트 (EEPROM) | 56 | 현재 위치 (2B) |
| 14 / 15 | 최대 / 최소 전압 (EEPROM, 0.1V) | 58 | 현재 속도 (2B) |
| 40 | 토크 ON/OFF | 60 | 부하 (2B, 0.1%) |
| 41 | 가속도 | 62 / 63 | 전압 (0.1V) / 온도 (℃) |
| 42 | 목표 위치 (2B) | 65 / 66 | 에러 상태 / 이동 중 |
| | | 69 | 전류 (2B, 6.5mA 단위) |
